# Write Essay

Create an essay prompt that elicits structured argument writing.

## Requirements
- Prompt: 20-60 words
- Should include argument words (agree, discuss, advantages, to what extent, etc.)
- Prompt should be clear and engaging
- Single key point or multiple perspectives possible

## JSON Example
```json
{
  "topic": "Workplace Technology",
  "passage": "",
  "essayPrompt": "Some people believe that advances in technology have made the workplace more efficient, while others argue that it has created more stress and distraction. Discuss both views and give your own opinion.",
  "keyPoints": null
}
```

## Instructions
Return ONLY the JSON object, no additional text.
